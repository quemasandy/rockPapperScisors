# 📋 Backlog del Producto

## Contexto

Este backlog reúne mejoras funcionales y técnicas que pueden incorporarse al
juego una vez priorizadas. A diferencia del roadmap de Clean Architecture, sus
tareas no forman una secuencia pedagógica obligatoria: cada una describe valor,
alcance, dependencias y criterios de aceptación.

- ⬜ Pendiente
- 🚧 En progreso
- ✅ Completada
- ⛔ Bloqueada

## Criterio de priorización

Las tareas se ordenan considerando valor para quien juega, dependencias
arquitectónicas, riesgo y esfuerzo. Agregar un elemento al backlog no implica que
ya esté comprometido para una entrega.
